# 🧮 Mobile Calculator — Qt6

A simple and clean **GUI calculator built with C++ and Qt6**.

This is my first hands-on project using the Qt framework, created to move from console-based C++ programs into **event-driven GUI application development**.

---

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔄 Clear / reset functionality
* 🖱️ Interactive button-based input
* 🎨 Custom dark-themed interface

---

## 🛠️ Built With

* **C++**
* **Qt6**
* **Qt Widgets**
* **Signals & Slots**

* Connecting GUI elements with C++ logic
* Basic Qt styling and interface design
